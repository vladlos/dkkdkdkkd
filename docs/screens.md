 Екран 1: Лобі / Пошук суперника (Matchmaking & Lobby)Мета: Підбір суперника за рейтингом (MMR), вибір теми або створення приватної кімнати.UI-компоненти:Хедер: Аватар користувача, нікнейм, поточний ранг/дивізіон, баланс енергії/монет.Вибір режиму: Таби або картки: «Випадковий суперник (Рейтинговий)», «Гра з другом (Код кімнати)», «Турнірна арена».Фільтр категорій: Горизонтальний скрол тегів (IT & Код, Історія, Кіно, Наука, Загальний мікс).Секція пошуку (Active Search Overlay):Радар/анімація пошуку суперника.Таймер очікування (00:14...).Кнопка «Скасувати пошук».Match Found Modal: Split-screen прев'ю — картка гравця зліва, картка суперника справа (аватар, країна, win rate), 3-секундний зворотний відлік до старту.Технічні події (WebSocket / State):emit: "matchmaking:join" — payload: { userId, categoryId, mode, mmr }.listen: "matchmaking:matched" — payload: { matchId, opponent: { id, name, avatar, mmr }, serverTimestamp }.emit: "matchmaking:cancel".2. Екран 2: Арена батлу (Live Battle Arena)Мета: Синхронне відображення запитання, таймера та динаміки очок у реальному часі.UI-компоненти:Top Bar (VS Status):Зліва: Аватарка + ім'я гравця, прогрес-бар балів, індикатор підключення (зелений/жовтий/червоний ping dot).По центру: Раунд (Раунд 3/7), категорія питання, круговий або лінійний таймер на запитання (10–15 сек).Справа: Аватарка + ім'я суперника, прогрес-бар його балів у реальному часі.Question Card:Текстове поле (підтримка форматування або коду/зображення за потреби).Бейдж складності (Easy / Med / Hard — впливає на коефіцієнт балів).Answer Grid:4 варіанти відповідей (2x2 або вертикальний стек).Стани кнопок: Default, Selected (пульсація), Correct (зелений), Wrong (червоний), Disabled.Live Feedback Layer:Індикатор суперника: бейдж «Суперник відповів» (без розкриття правильності до завершення раунду або розкриття з нарахуванням очок).Streak Counter (бонус за серію правильних відповідей: x1.2, x1.5).Технічні події (WebSocket / State):listen: "round:start" — payload: { roundNumber, questionId, text, options: [{id, text}], timeLimitMs, serverStartTime }.emit: "round:submit_answer" — payload: { matchId, roundNumber, selectedOptionId, responseTimeMs }.listen: "opponent:answered" — payload: { opponentId, answered: true, timeRemainingMs }.listen: "round:result" — payload: { correctOptionId, scores: { player: num, opponent: num }, deltas: { player: num, opponent: num } }.3. Екран 3: Результати матчу (Match Summary & Post-Game)Мета: Підбиття підсумків гри, фіксація змін у рейтингу, утримання гравця (Retention).UI-компоненти:Header: Статус матчу («Перемога!», «Поразка», «Нічия») з анімацією конфеті або віньєткою.Порівняльна картка (Head-to-Head Stats):Підсумковий рахунок (наприклад, 1450 : 1120).Метрики: Точність (%), середній час відповіді (сек), максимальний стрік.Progression Box:Зміна рангу/MMR: анімований лічильник (+24 MMR або -15 MMR).Отриманий досвід (XP) та внутрішньоігрова валюта.   Action Bar:Кнопка «Реванш» (відправляє інвайт супернику, таймер очікування 10 сек).Кнопка «Наступний бій» (швидкий перезапуск matchmaking).Кнопка «Розбір помилок» (відкриває модальне вікно з правильними відповідями та поясненнями).Технічні події (WebSocket / State):listen: "match:ended" — payload: { winnerId, finalScores, mmrDelta, rewards: { xp, coins } }.emit: "match:rematch_request" — payload: { matchId }.listen: "match:rematch_status" — payload: { accepted: boolean }.4. Допоміжний стан: Розрив з'єднання (Reconnection & Timeout Overlay)Мета: Обробка втрати зв'язку та запобігання чітерству.UI-компоненти:Неблокуючий тост або напівпрозорий оверлей: «Відновлення зв'язку...».Зворотний таймер утримання слота (наприклад, 15 секунд до зарахування технічної поразки).Для опонента: напис «Суперник перепідключається...».Технічна логіка:Автоматичний reconnect через Exponential Backoff.Heartbeat / Ping-pong кожні 3–5 секунд.Синхронізація клієнтського таймера із серверним serverTimestamp для нівелювання затримок мережі.
